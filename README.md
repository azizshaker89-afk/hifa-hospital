# مستشفى الشفاء التخصصي — Al Shifa Specialized Hospital

موقع حجز مواعيد لمستشفى (واجهة أمامية فقط) — عربي/إنجليزي، وضع فاتح/داكن، وأسعار تتغير حسب الدولة.

A hospital appointment-booking website (front end only): Arabic/English, light/dark mode, and per-country pricing.

## الصفحات / Pages
- `index.html` — الرئيسية / Home
- `doctors.html` — الأطباء / Doctors (search, filter, sort)
- `departments.html` — الأقسام / Departments
- `booking.html` — احجز موعدك / Booking (validation, promo code `SHIFA10`, confirmation)
- `about.html` — عن المستشفى / About
- `contact.html` — تواصل معنا / Contact

## التشغيل / Run
Static site, no build step: open `index.html` in a browser, or serve the folder with any static server.

## ملاحظات / Notes
- Doctor names, phone numbers, prices and the address are fictional.
- Photos are free images from [Unsplash](https://unsplash.com).
- Forms are demos and don't send data to a server.
